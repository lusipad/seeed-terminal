# 小维 v2 设计:情绪性格 + 响应提速

> 日期:2026-10-01 · 范围:`pet/` 固件 · 状态:待用户审阅

## 1. 目标与约束

**目标**
1. **情绪与性格**:活泼元气人设;情绪从四处体现——回答带情绪标签、等待动画、待机小动作、传感器互动
2. **更快的响应**:从"说完话"到"回答上屏"的耗时比基线缩短 ≥5 秒

**约束**
- 必须独立运行:不依赖 PC,板子自己完成全部网络请求
- AI 全部继续使用 Web API(百度 ASR + DeepSeek),不在本地跑模型
- 局部重绘,禁止整屏刷新(闪烁,用户已否决过)
- RAM:192KB 中录音缓冲占 96KB,表情一律几何绘制,不用图片素材
- 不安装 PC 端 C++ 编译器;逻辑测试在板上自检

**不在本版范围(YAGNI)**:对话记忆、提醒、天气等实时信息、PC 联动、流式回复。

## 2. 架构

### 2.1 模块

| 文件 | 状态 | 职责 |
|---|---|---|
| `pet/pet.ino` | 改 | 状态机:IDLE / RECORD / THINK / SHOW + 新增 SLEEP;分发传感器事件 |
| `pet/pet_face.h` | 改 | 表情绘制:6 种 → 12 种;装饰层(星光、!、?、泪滴、♪、Zzz、声波) |
| `pet/pet_anim.h` | 新 | 动画调度器:`petAnimSet(anim)`、`petAnimTick()`,按 `millis()` 推进,非阻塞 |
| `pet/pet_sense.h` | 新 | 光线 + IMU 采样 → 事件(DARK / LIGHT / SHAKE / PICKUP) |
| `pet/pet_logic.h` | 新 | **无 Arduino 依赖**的纯逻辑:HTTP 响应完整性判断、chunked 解码、情绪标签解析 |
| `pet/voice_pet.h` | 改 | 提速改造 + 等待循环内调用 `petAnimTick()` + 情绪标签 |
| `tests/pet_selftest/` | 新 | 板上自检 sketch:引入 `pet_logic.h`,上电跑断言,串口输出 PASS/FAIL |

注:Arduino 会把 sketch 复制到临时目录编译,跨目录 `../` 引用会断(HANDOFF 已记录)。`tests/pet_selftest/` 需持有 `pet_logic.h` 的拷贝,由一个同步步骤保证两份一致(实现计划中定义)。

### 2.2 屏幕分区(320×240)

| 区域 | 范围(约) | 内容 |
|---|---|---|
| 气泡区 | y 0–100 | 对话气泡(现有 `drawBubbleText`) |
| 脸部区 | 以 (160,152) 为中心、半径 40 的脸 + 两侧/上方装饰区 | 眼、嘴、腮红、装饰 |
| 提示区 | y 212–240 | 提示文字(连接中、按 B 说话等) |

动画只写自己的区域,永不覆盖气泡区。精确坐标在实现时以现有 `pet_face.h` 常量为准。

### 2.3 一次对话的数据流

```
按 B → 聆听动画 → VAD 自动截断
     → 思考动画(网络等待循环中持续 petAnimTick)
     → DeepSeek 返回 "[惊讶]哇,你居然…" → 解析标签 → 惊讶表情 + 气泡(标签不显示)
     → 15 秒或按键 → 回待机
```

## 3. 响应提速

### 3.0 先测量
- 每轮对话结束串口打印一行计时:`T: trail=… upload=… asr=… llm_conn=… llm=… total=…`(单位 ms)
- 修复上次日志只落盘到 `HELLO` 的问题(排查 `tools/flash_and_log.sh` 的串口监听)
- 改动前先采一组基线(至少 3 轮)

### 3.1 优化项

| # | 改动 | 预期 |
|---|---|---|
| S1 | **按协议判断响应结束**:解析响应头,有 `Content-Length` 则收满即停;chunked 则遇到终止块 `0\r\n\r\n` 即停;两者都没有时退回"3 秒无新数据"兜底 | 每轮省约 6s |
| S2 | **开机预连**:开机即连 WiFi + 取百度 token(配"醒来"动画);ASR 返回 `err_no` 110/111(token 失效)时自动重取并重试一次 | 首轮省 3–5s |
| S3 | 静音截断 `PET_TRAILING_MS` 1300 → 900,实测后微调 | ~0.4s |
| S4 | DeepSeek `max_tokens` 300 → 120 | 限制最坏耗时 |
| S5 | **条件项**:若测量显示 `llm_conn` > 1500ms,尝试 DeepSeek keep-alive 复用连接,被断开则自动重连;否则不做 | 可能 1–3s |

### 3.2 成功标准
- 说完 → 上屏 的中位耗时比基线缩短 ≥5s
- 连续 10 轮对话的成功率不低于基线

## 4. 动画与情绪

### 4.1 表情集(12 种)

已有:平常、眨眼、开心、难过、聆听、思考
新增:兴奋、惊讶、害羞、疑惑、困/睡着、晕

### 4.2 动画

| 动画 | 触发 | 内容 | 帧间隔 |
|---|---|---|---|
| IDLE | 默认 | 随机 2.5–5s 眨眼一次 | — |
| LISTEN | 录音中 | 头两侧声波弧线轮流亮起 | ~150ms |
| THINK | 网络等待 | 眼睛左右看 + "· → ·· → ···" 循环 | ~300ms |
| EMOTE | 显示回答 | 对应表情 + 装饰(兴奋=星光、惊讶=!、害羞=腮红、疑惑=?、难过=泪滴) | 一次性 + 轻微循环 |
| WAKE | 开机/联网/唤醒 | 眼睛慢慢睁开 + 提示区"连接中…" | ~120ms |
| DROWSY | 3 分钟无互动 | 半眯眼,偶尔打哈欠 | — |
| SLEEP | 5 分钟无互动或关灯 | 闭眼 + 飘 "Zzz",背光调暗(若背光不支持 PWM 则不调亮度) | ~500ms |
| DIZZY | 被摇晃 | 蚊香眼,持续 3s | ~100ms |
| IDLE_ACT | 待机每 8–20s 随机 | 左右张望 / 哼歌(♪ 上飘)/ 歪头 | — |

**防闪烁规则**
- 身体轮廓不重绘;只改眼、嘴、装饰层,改前先用底色擦除旧内容
- `petAnimTick()` 每次最多画一帧,耗时控制在几毫秒内;未到下一帧时间直接返回

**在阻塞网络期间的调用点**
- `readHttpBody` 读取循环(每 ~5ms 一次)
- 上传时 `b64OutPush` 每写出一个 1KB 块后
- 已知局限:TLS 握手期间卡在库内部,动画会短暂停顿;S2 开机预连可减少握手次数

### 4.3 情绪标签

- 系统提示词:保持活泼元气人设;**回答必须以 `[情绪]` 开头**,情绪只能是 `开心/兴奋/惊讶/害羞/疑惑/难过` 之一;正文 45 字以内
- 解析(`pet_logic.h`):若以 `[` 开头且在前 16 字节内找到 `]`,取中间文字映射到表情并剥离(含其后空白);无标签或不在白名单 → "开心",原文完整显示

## 5. 传感器(`pet_sense.h`)

- **光线**:`analogRead(WIO_LIGHT)` 每 500ms 采样,滑动平均;双阈值迟滞:暗于 `DARK_TH` 持续 10s → DARK;亮于 `LIGHT_TH` 持续 2s → LIGHT。阈值由实现时串口打印 `S: light=…` 实测标定
- **IMU**:安装官方库 `Seeed Arduino LIS3DHTR`(Wire1);每 50ms 读加速度
  - SHAKE:1s 内多次 |a| 偏离 1g 超过阈值 → 晕 3s,之后 5s 冷却
  - PICKUP:静止后出现明显姿态变化 → 唤醒
  - 初始化失败:仅禁用 IMU 功能并打印日志,其他照常
- **摇杆左右 = 摸头**:保留
- **事件过滤**:仅在 IDLE / SHOW / SLEEP 状态处理传感器事件;RECORD / THINK 期间忽略

## 6. 异常处理

| 情况 | 处理 |
|---|---|
| 开机 WiFi 失败 | 离线照常做宠物(动画、传感器);按 B 时再重连 |
| 百度 token 失效 | 自动重取,重试一次 |
| 网络/识别/DeepSeek 失败 | 难过表情 + 小维口吻的简短原因(保留现有 note 机制) |
| 响应头无长度信息 | 退回 3 秒无数据兜底 |

## 7. 测试与验收

**板上逻辑自检(`tests/pet_selftest/`)**,覆盖 `pet_logic.h`:
- 响应完整性:Content-Length 收满/未收满、chunked 有/无终止块、头部未收全
- chunked 解码:单块、多块、空块
- 情绪标签:六种合法标签、无标签、非法标签、`]` 缺失、标签后带空格

**编译检查**:每次改动 `pet` 与 `pet_selftest` 都须编译通过。

**真机验收(需用户配合)**
1. 计时:优化前后各 ≥3 轮,中位耗时缩短 ≥5s
2. 连续 10 轮对话成功率不低于基线
3. 每种表情/动画目视正常、无闪烁、不覆盖气泡
4. 遮住光线传感器 → 睡;移开 → 醒;摇晃 → 晕;拿起 → 醒
