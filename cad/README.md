## 🎨 外壳方案对比

### 🌟 旗舰推荐方案：可自由俯仰摆动的复古小电视监视器 (`wio_tilt_tv`)
结合了“复古小电视”的颜值与“仰角自由调节”的人机工学：
- **机头组件 (`wio_tilt_tv_head.stl`)**：
  - 复古 CRT 电视机造型，正面前框带有微弧显像管包裹视窗；
  - 右侧浮雕双旋转旋钮与摇杆操作开口，顶部露出 A/B/C 三个操作按键；
  - 顶部自带萌系猫咪立体耳朵；
  - 背部隐藏式功能腔室（可容纳 MAX98357A I2S 功放模块、腔体喇叭与 1000mAh 锂电池）；
  - 底部延伸出铰链转轴凸耳（Lug）。
- **底座组件 (`wio_tilt_tv_base.stl`)**：
  - 桌面大面积低重心稳固底盘，带有底部防滑垫沉槽；
  - 向上伸出复古双叉支架臂（Clevis），抱紧机头转轴；
  - **支持 0°（垂直）到 45°（大幅度仰视）无级平滑摆动**！
- **阻尼旋钮 (`wio_tilt_tv_knob.stl`)**：
  - 侧边手拧调节旋钮，内嵌 M3/M4 螺栓。用手指轻轻一拧即可锁死在最舒服的角度，松开就能随手上下扳动摆头！

## 🏭 3D 打印与代打指引（无打印机也能做）

国内代打极其便宜（一般 **15 ~ 25 元包邮到家**），推荐使用微信小程序或网页平台：
- **嘉立创三维猴 (JLC3D)** / **捷配** / **淘宝 3D 打印店**

### 推荐打印参数与材质
1. **材质首选：9000E 白色光敏树脂（工业 SLA 光固化）**
   - **理由**：表面极其致密光洁，手感类似高档陶瓷或苹果产品外壳；无 FDM 熔融层纹；孔径公差精准（±0.1mm）。
   - **配色建议**：机头选用“象牙白/奶白”，底座选用“复古灰/深灰”，旋钮选用“金色/原色”，质感媲美原厂工艺品。
2. **自行使用 3D 打印机（FDM / 拓竹 Bambu / 创想）：**
   - 耗材推荐：PLA+ 或 PETG。
   - 层高：`0.16mm` ~ `0.20mm`。
   - 填充率：`20%` ~ `30%`。
   - 摆放方向：机头背面朝下平放，底座底面贴床平放，极少需要支撑。

## 🛠️ 重新生成与二次开发

- **在 OpenSCAD 中预览装配与动画**：
  打开 `cad/wio_tilt_tv.scad`，修改 `tilt_deg = 30` 即可实时预览摆动形态，修改 `mode = "head"` / `"base"` / `"knob"` 即可分别导出不同组件。
- **命令行一键更新 STL**：
  在项目根目录运行：
  ```bash
  python tools/generate_3d_models.py
  ```
