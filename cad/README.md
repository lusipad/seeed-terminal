## 🎨 两套外壳方案介绍

### 方案 1：30° 黄金视距多功能桌面底座与音腔背壳 (`wio_desktop_dock.stl`)

- **定位**：适合桌宠日常互动、75px 赛博时钟看板与番茄钟倒计时。
- **核心特点**：
  - **30° 仰角黄金视距**：将屏幕斜立放置在桌面上，无论坐姿还是站立，视线无需低头即可清晰阅读。
  - **100% 露出原厂操作区**：顶部 3 个按键（A/B/C）、五向摇杆与整块 2.4 寸屏幕毫无遮挡。
  - **内嵌音腔与电池仓**：背部隐藏式空腔（60mm x 45mm x 18mm），可完美收纳 I2S 功放板、共鸣腔小喇叭与 1000mAh 锂电池。
  - **背部声学导音槽**：带有百叶窗式阵列出音槽，声音通透洪亮。
  - **侧边 Type-C 走线槽**：无需将设备拆出底座即可插线充电。
  - **无损固定**：利用 Wio Terminal 背部自带的 2 个 M3 铜螺母（间距 40mm）拧紧锁固。

### 方案 2：复古迷你 CRT 小电视 / 猫耳外壳 (`wio_retro_tv.stl`)

- **定位**：桌面潮玩、复古极客摆件，完美契合像素小猫人设。
- **核心特点**：
  - **CRT 电视机微缩造型**：复古圆角显像管视窗边框，右侧自带双复古调节旋钮浮雕与斜撑脚架。
  - **顶部萌宠猫耳**：自带立体微型小耳朵，极富个性。
  - **滑动滑入结构**：设备可自后方直接滑入卡紧。

## 🏭 3D 打印与代打指引（无打印机也能做）

国内代打极其便宜（一般 **15 ~ 25 元包邮到家**），推荐使用微信小程序或网页平台：
- **嘉立创三维猴 (JLC3D)** / **捷配** / **淘宝 3D 打印店**

### 推荐打印参数与材质
1. **材质首选：9000E 白色光敏树脂（工业 SLA 光固化）**
   - **理由**：表面极其致密光洁，手感类似高档陶瓷或苹果产品外壳；无 FDM 熔融层纹；孔径公差精准（±0.1mm）。
   - **表面处理**：选择“打磨 + 喷油（哑光白）”或直接原色白。
2. **自行使用 3D 打印机（FDM / 拓竹 Bambu / 创想）：**
   - 耗材推荐：PLA+ 或 PETG（韧性更好）。
   - 层高：`0.16mm` ~ `0.20mm`。
   - 填充率：`20%` ~ `30%`（Grid 或 Gyroid 陀螺形填充）。
   - 壁厚层数：3 层以上。
   - 支撑设置：树状支撑（Tree Support），便于拆卸。

## 🔌 免焊接“发声完整体”硬件选型清单 (BOM)

本方案实现 **完全免焊（0 焊锡，插拔即用）**：

| 配件名称 | 规格型号建议 | 淘宝/拼多多搜索关键词 | 参考单价 | 作用 |
| :--- | :--- | :--- | :--- | :--- |
| **I2S 功放模块** | MAX98357A（**选“已焊排针”版本**） | `MAX98357A 已焊排针` | 5 ~ 8 元 | 高保真数字音频放大 |
| **共鸣腔小喇叭** | 8Ω 2W 腔体喇叭（带杜邦端子/导线） | `8欧2瓦 腔体喇叭 3520` | 4 ~ 6 元 | 紧凑音腔，人声清晰洪亮 |
| **杜邦连接线** | 10cm 母对母优质杜邦线（5~7 根） | `10cm 母对母杜邦线` | 2 ~ 3 元 | 免焊接连接 40-Pin 与功放 |
| **紧固螺丝** | M3 * 6mm 或 M3 * 8mm 盘头螺丝（2 颗） | `M3 螺丝 6mm` | 1 元 | 锁紧 Wio Terminal 背部螺母 |
| **锂电池（可选）** | 3.7V 603040 / 503040（800~1000mAh，带保护板） | `3.7V 锂电池 603040` | 10 ~ 15 元 | 彻底脱离线缆供电 |

## 📌 MAX98357A 到 Wio Terminal 40-Pin 极简免焊接线表

将杜邦线母头直接插到 Wio Terminal 背部 40-Pin 插座和 MAX98357A 排针上：

```text
Wio Terminal 40-Pin 插座                       MAX98357A 功放板
┌───────────────────────┐                     ┌─────────────────┐
│ Pin 2 或 Pin 4 (5V)   │ ══════════════════> │ VIN             │
│ Pin 6 或 Pin 9 (GND)  │ ══════════════════> │ GND             │
│ Pin 12 (BCM 18 / BCLK)│ ══════════════════> │ BCLK            │
│ Pin 35 (BCM 19 / LRC) │ ══════════════════> │ LRC             │
│ Pin 40 (BCM 21 / DIN) │ ══════════════════> │ DIN             │
└───────────────────────┘                     │ GAIN (悬空=9dB) │
                                              │ SD (悬空/接高)  │
                                              └────────┬────────┘
                                                       │ 拧螺丝夹紧导线
                                                       ▼
                                              ┌─────────────────┐
                                              │ 8Ω 2W 腔体喇叭  │
                                              └─────────────────┘
```

## 🛠️ 二次修改与官方图纸源

- **修改模型**：可在本目录直接用 [OpenSCAD](https://openscad.org/) 打开 `wio_desktop_dock.scad` 或 `wio_retro_tv.scad` 调整倾斜角度和空腔壁厚。
- **重新导出 STL**：在项目根目录运行 `python tools/generate_3d_models.py` 即可一键更新所有 STL 资产。
- **官方 3D 原始 STEP 工业模型**：Seeed Studio 官方完整装配体见 [OSHW-WioTerminal (GitHub)](https://github.com/Seeed-Studio/OSHW-WioTerminal/tree/main/07%203D%20Models%20of%20the%20Enclosure)。
